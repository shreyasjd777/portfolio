# Shreyas Deshpande Portfolio

A React and Vite portfolio site for Shreyas Deshpande. It includes responsive project, experience, education, and contact sections with persisted light/dark theme support.

## Requirements

- Node.js 20.19+ (or 22.12+)
- npm

## Development

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

Run the production checks:

```bash
npm run lint
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
